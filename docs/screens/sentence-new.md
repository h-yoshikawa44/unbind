# 英文追加ページ

## 概要

新しい英文を入力するページ。英文本文に加えてタグ（「過去文」「あいさつ文」など）を任意で付与できる。送信すると英文をスペース区切りでトークンに分解し、英文詳細ページへ遷移する。

## ルート

| 項目                 | 値                                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| URL                  | `/sentences/new`                                                                                     |
| サーバルート         | `GET /sentences/new`（`app/server.tsx`）。`fetchAllTags()` を props で渡す。作成は `POST /sentences` |
| ページコンポーネント | `app/pages/Sentences/New.tsx`（props を `PageProps<'Sentences/New'>` で受領）                        |
| UIコンポーネント     | `src/components/SentenceForm/SentenceForm.tsx`, `src/components/TagInput/TagInput.tsx`               |

## 画面レイアウト

```
┌──────────────────────────────────────────────────────┐
│ [Unbind]  英文分解・翻訳アシスタント                  │  ← 共通ヘッダー
├──────────────────────────────────────────────────────┤
│  英文を入力                                           │  ← フォームタイトル
│ ┌────────────────────────────────────────────────┐   │
│ │ 例: The quick brown fox jumps over the lazy    │   │  ← テキストエリア
│ │ dog.                                           │   │
│ │                                                │   │
│ └────────────────────────────────────────────────┘   │
│  タグ                                                 │  ← タグ入力ラベル
│ ┌────────────────────────────────────────────────┐   │
│ │ (過去文 ×) 例: 過去文（Enter で追加）           │   │  ← タグ入力欄
│ └────────────────────────────────────────────────┘   │
│                          [キャンセル]  [分解する]     │  ← アクション
└──────────────────────────────────────────────────────┘
```

## 要素仕様

### フォーム

| 要素             | 種別                      | 説明                                                                  |
| ---------------- | ------------------------- | --------------------------------------------------------------------- |
| 英文を入力       | 見出し (`h2`)             | フォームタイトル                                                      |
| テキストエリア   | `textarea`                | 英文を入力する。ページ表示時に自動フォーカス (`autoFocus`)。行数は3行 |
| プレースホルダー | テキスト                  | `例: The quick brown fox jumps over the lazy dog.`                    |
| `キャンセル`     | ボタン (outline)          | 英文一覧ページへ戻る                                                  |
| `分解する`       | ボタン (primary / submit) | 英文を送信して分解処理を実行する                                      |

### タグ入力（`TagInput`）

英文へ任意のタグを付与する入力欄。入力は任意で、タグなしでも送信できる。

| 要素           | 種別                | 説明                                                                        |
| -------------- | ------------------- | --------------------------------------------------------------------------- |
| タグ           | ラベル              | 入力欄の見出し                                                              |
| タグチップ     | チップ + `×` ボタン | 追加済みのタグ。`×` クリックでそのタグを削除                                |
| 入力フィールド | `text` 入力         | タグ文字列を入力する。`datalist` で既存タグ（`fetchAllTags()`）をサジェスト |

**タグ入力の挙動:**

| 操作                                  | 結果                                             |
| ------------------------------------- | ------------------------------------------------ |
| `Enter` または `,`（カンマ）を入力    | 入力中の文字列をタグとして追加し、入力欄をクリア |
| 入力欄が空の状態で `Backspace`        | 末尾のタグを削除                                 |
| タグチップの `×` をクリック           | そのタグを削除                                   |
| 入力欄からフォーカスが外れる (`blur`) | 入力中の文字列があればタグとして追加             |

タグは `normalizeTags()` で正規化される（前後空白の除去・空文字の除外・重複排除。順序は保持）。

### バリデーション

| 条件                              | 挙動                                   |
| --------------------------------- | -------------------------------------- |
| テキストが空（空白のみを含む）    | `分解する` ボタンを無効化 (`disabled`) |
| テキストが1文字以上（空白除去後） | `分解する` ボタンを有効化              |

送信時にもテキストをトリムし、空の場合は何もしない（二重防止）。

## ユーザー操作

| 操作                                        | 結果                                                 |
| ------------------------------------------- | ---------------------------------------------------- |
| テキストエリアに英文を入力                  | `分解する` ボタンが有効になる                        |
| `分解する` をクリック（またはフォーム送信） | 英文を保存してトークン分解、`/sentences/{id}` へ遷移 |
| `キャンセル` をクリック                     | `/` へ遷移                                           |

## 英文分解処理フロー

1. テキストをトリムし、タグを正規化して `onSubmit(text, tags)` を呼び出す
2. `crypto.randomUUID()` で新しい英文IDを生成
3. `tokenize(id, text)` でスペース区切りのトークン配列を生成（各トークンはランダムUUID付与）
4. `router.post('/sentences', toPayload({ id, text, tokens, tags }))` を呼ぶ（tokenize はクライアント側で実施）
5. サーバの `POST /sentences`（`createSentence`）が JSON ファイルに保存し、`/sentences/{id}` へ 303 リダイレクト → 詳細ページが表示される

## 画面遷移

```
英文一覧ページ (/)  ──[+ 英文を追加]──→  英文追加ページ (/sentences/new)
                                             │
                           [キャンセル] ─────┤
                                ↓            │ [分解する]
                          英文一覧 (/)        ↓
                                       英文詳細ページ (/sentences/{id})
```

## ページ状態

フォームの入力状態は `SentenceForm` コンポーネントが内部で保持する。ページ (`New`) はタグ候補（props）のみを扱う。

| 状態変数         | 型         | コンポーネント | 説明                                                             |
| ---------------- | ---------- | -------------- | ---------------------------------------------------------------- |
| `text`           | `string`   | `SentenceForm` | テキストエリアの入力値                                           |
| `tags`           | `string[]` | `SentenceForm` | 付与したタグの一覧                                               |
| `tagSuggestions` | `string[]` | `New`（props） | タグ入力のサジェスト候補。サーバの `GET /sentences/new` から受領 |

## サーバとのやり取り（Inertia）

| タイミング     | 方式                                          | 説明                                                                                                         |
| -------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| ページ表示     | `GET /sentences/new` → props                  | `fetchAllTags()` の既存タグをサジェスト候補として props で受領                                               |
| フォーム送信時 | `router.post('/sentences', toPayload({...}))` | サーバの `POST /sentences`（`createSentence`）が JSON ファイルに保存し `/sentences/{id}` へ 303 リダイレクト |
