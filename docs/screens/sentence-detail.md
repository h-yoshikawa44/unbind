# 英文詳細ページ

## 概要

英文のトークン分解・品詞分析を行うページ。英文をトークン（単語・フレーズ）単位で操作し、各トークンへの品詞・語形・意味の入力と意訳の記入ができる。複数のトークン（隣接していなくてもよい）をパターン（熟語・パターン・文法パターン。例: `turn … off`, `have … been`）として登録し、単語ごとの分析とは別にパターンとしての意味を記入することもできる。あわせて英文へのタグ（「過去文」「あいさつ文」など）の付与・編集もできる。

## ルート

| 項目                 | 値                                                                                                                                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| URL                  | `/sentences/:id`                                                                                                                                                                                     |
| サーバルート         | `GET /sentences/:id`（`app/server.tsx`）。対象 `sentence`（無ければ `null`）と `fetchAllTags()` を props で渡す。保存は `PUT /sentences/:id`                                                         |
| ページコンポーネント | `app/pages/Sentences/Show.tsx`（props を `PageProps<'Sentences/Show'>` で受領）                                                                                                                      |
| UIコンポーネント     | `src/components/SentenceEditor/SentenceEditor.tsx`, `src/components/PatternConnectors/PatternConnectors.tsx`, `src/components/PatternPanel/PatternPanel.tsx`, `src/components/TagInput/TagInput.tsx` |

**トークン未選択時（通常モード）:**

```
  トークンをクリックして分析情報を入力できます   ← 空ヒント
```

**隣接フレーズ作成モード中:**

```
  トークン操作:  [選択中...]  [グループ化]   ← 隣接選択時にグループ化ボタンが出現
               隣接したトークンのみグループ化できます  ← 非隣接選択時に警告
               グループ化したいトークンを選択してください  ← 未選択時のヒント
```

**パターン作成モード中:**

```
  トークン操作:  [選択中...]  [パターンに登録]   ← 2つ以上選択時に登録ボタンが出現（隣接していなくてよい）
               パターンを構成するトークンを2つ以上選択してください（離れていても選べます）  ← 選択が2つ未満のときのヒント
```

### 隣接フレーズとパターンの違い

| 種別         | データ                                    | トークン                           | 用途                                                                                                                             |
| ------------ | ----------------------------------------- | ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 隣接フレーズ | `Token.memberTexts`（トークン自体を結合） | 隣接したトークンを 1 つに結合する  | 1 語として扱う語句（`looked up` に品詞・変化形をまとめて付けるなど）                                                             |
| パターン     | `Sentence.patterns`（トークンへの参照）   | 結合しない。隣接していなくてもよい | 熟語・慣用句（`turn … off`）や文法パターン（`have … been`, `not only … but also`）に、単語ごとの品詞・訳を保ったまま意味を付ける |

## 要素仕様

### エディターヘッダー

| 要素         | 種別             | 説明                                                                            |
| ------------ | ---------------- | ------------------------------------------------------------------------------- |
| `← 戻る`     | ボタン (outline) | 英文一覧ページへ戻る。未保存の変更がある場合は確認ダイアログを表示              |
| 英文テキスト | テキスト (`p`)   | 英文の原文を表示（編集不可）                                                    |
| `保存`       | ボタン (primary) | 分析データを `router.put` でサーバに保存する。変更がない場合は無効 (`disabled`) |

### トークンツールバー

| 要素                 | 種別                     | 説明                                                                                     |
| -------------------- | ------------------------ | ---------------------------------------------------------------------------------------- |
| `隣接フレーズを作成` | ボタン (outline / small) | 隣接フレーズ作成モードをONにする（パターン作成モード中は非表示）                         |
| `パターンを作成`     | ボタン (outline / small) | パターン作成モードをONにする（隣接フレーズ作成モード中は非表示）                         |
| `選択中...`          | ボタン (active / small)  | 各モードON時に表示。クリックでモードをOFFにする                                          |
| `グループ化`         | ボタン (primary / small) | 隣接する2つ以上のトークンを選択した場合に出現。クリックでフレーズトークンに合成する      |
| `パターンに登録`     | ボタン (primary / small) | パターン作成モードで2つ以上のトークンを選択した場合に出現。クリックでパターンを追加する  |
| 警告テキスト         | テキスト                 | 非隣接トークンを選択した場合に「隣接したトークンのみグループ化できます」を表示           |
| ヒントテキスト       | テキスト                 | 隣接フレーズ作成モードON・未選択時に「グループ化したいトークンを選択してください」を表示 |
| ヒントテキスト       | テキスト                 | パターン作成モードON・選択が2つ未満のときに構成トークンの選択を促す                      |

### トークンチップ

各トークンはボタン要素として表示される。

| 要素             | 条件                               | 説明                                                            |
| ---------------- | ---------------------------------- | --------------------------------------------------------------- |
| トークンテキスト | 常時                               | 単語またはフレーズの表示テキスト                                |
| 品詞バッジ       | 通常モード・品詞設定済み           | 品詞名を色付きバッジで表示（後述）                              |
| 語形バッジ       | 通常モード・動詞の語形設定済み     | 動詞変化形名をバッジで表示                                      |
| 数バッジ         | 通常モード・名詞の数設定済み       | 単数形/複数形をバッジで表示                                     |
| 用法バッジ       | 通常モード・to不定詞の用法設定済み | 名詞的/形容詞的/副詞的用法をバッジで表示                        |
| 語義テキスト     | 通常モード・語義入力済み           | 単語の意味を最大2行で表示                                       |
| 慣用句テキスト   | 通常モード・慣用句の意味入力済み   | 「慣: {意味}」の形式で表示（フレーズトークンの `idiomMeaning`） |

### パターンの連結線（`PatternConnectors`）

パターンごとに、構成トークンのチップ下端から縦線を下ろし、横線でつないだブラケット状の線を描く。線の上に「番号 + パターンの意味」のラベル（未入力なら「意味未入力」）を載せる。番号は `Sentence.patterns` の並び順（1 始まり）で、パターンパネルの「パターン{番号}」と対応する。

ラベルはボタンになっており、クリックするとパターンパネルを開く（もう一度クリックで閉じる）。開いているパターンはラベルを塗りつぶし、線を太くして強調する（`aria-pressed`）。隣接フレーズ作成・パターン作成モード中はラベルを押せない（`disabled`）。

| 項目         | 仕様                                                                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| ラベルの表示 | 意味は幅 12rem で折り返し、2 行まで表示する。3 行目以降は「…」で省略する（全文はパターンパネルで確認・編集する）                                   |
| 位置の計測   | `usePatternConnectors` がチップの `offsetLeft/Top/Width/Height` とラベルの実寸を測り、`layoutPatternConnectors()`（`layout.ts`）で配置を計算       |
| 再計測       | `tokens` / `patterns` の変化時、配置の変化で描き直したラベルの実寸が変わったとき、トークン領域・各チップのサイズ変化時（`ResizeObserver`）         |
| 段の割り当て | 同じ行で重なる線は段を分ける（ラベルが線より広いときはラベルの幅で判定）。短い線ほど上の段にし、入れ子のパターンで縦線と横線が交差しないようにする |
| 行間         | 線の段数と一番高いラベル（2 行なら 2 行ぶん）に合わせて、段の間隔とトークン一覧の行間・下余白を広げる                                              |
| 行をまたぐ   | 行ごとに線を分け、続く側は行端まで伸ばして端をフェードさせる。ラベルは最初の行にだけ置く                                                           |
| 支援技術     | 線は装飾扱い（`aria-hidden`）。ラベルは「パターン「{構成単語}」を編集」という名前のボタンとして公開する                                            |

**チップのスタイル状態:**

| 状態       | CSS クラス              | 条件                                               |
| ---------- | ----------------------- | -------------------------------------------------- |
| 通常       | `.token-chip`           | デフォルト                                         |
| フレーズ   | `.token-chip--phrase`   | `memberTexts.length > 1`                           |
| アクティブ | `.token-chip--active`   | 通常モードで選択中                                 |
| 選択済み   | `.token-chip--selected` | 隣接フレーズ作成モード・パターン作成モードで選択中 |

フレーズの結合・分解でトークンが入れ替わった場合、パターンの参照は自動で追従する（結合後のフレーズトークン／分解後の各単語を参照する）。

### 意訳エリア

| 要素           | 種別             | 説明                                                                           |
| -------------- | ---------------- | ------------------------------------------------------------------------------ |
| 意訳           | ラベル (`label`) | テキストエリアのラベル                                                         |
| テキストエリア | `textarea`       | 文章全体の自然な日本語訳を入力する。行数は3行。変更時に `isDirty` をtrueにする |

### タグエリア（`TagInput`）

英文へ付与するタグの表示・編集を行う。

| 要素           | 種別                | 説明                                                                        |
| -------------- | ------------------- | --------------------------------------------------------------------------- |
| タグ           | ラベル              | タグエリアの見出し                                                          |
| タグチップ     | チップ + `×` ボタン | 付与済みのタグ。`×` クリックで削除                                          |
| 入力フィールド | `text` 入力         | タグ文字列を入力する。`datalist` で既存タグ（`fetchAllTags()`）をサジェスト |

タグ入力の挙動（`Enter`/`,` で追加、空欄で `Backspace` により末尾削除、`blur` で確定、`normalizeTags()` による正規化）は英文追加ページと共通。タグを変更すると `isDirty` がtrueになり、`保存` ボタンが有効化される。

### パターンパネル（`PatternPanel`。パターンラベルのクリック時のみ表示）

連結線上のラベルをクリックした場合と、パターンを登録した直後に、分析パネルと同じ位置に表示される（分析パネルとは同時に開かない）。見た目は分析パネルと共通。

| 要素           | 種別                     | 説明                                                                                          |
| -------------- | ------------------------ | --------------------------------------------------------------------------------------------- |
| 種別ラベル     | テキスト                 | 「パターン{番号}」。連結線のラベルの番号と対応する                                            |
| 構成単語       | テキスト                 | 構成トークンを英文中の順に表示。隣接していないトークンの間は「…」でつなぐ（例: `turn … off`） |
| `削除`         | ボタン (outline / small) | パターンを削除してパネルを閉じる（トークンの分析は残る）                                      |
| パターンの意味 | テキストエリア           | パターンの意味を入力する。開いたときにフォーカスし、カーソルを末尾に置く                      |

### 分析パネル（トークン選択時のみ表示）

通常モードでトークンチップをクリックした場合に表示される。隣接フレーズ作成モード中は非表示。

#### パネルヘッダー

| 要素             | 種別                     | 条件                 | 説明                                                   |
| ---------------- | ------------------------ | -------------------- | ------------------------------------------------------ |
| 種別ラベル       | テキスト                 | 常時                 | フレーズトークンは「フレーズ」、通常トークンは「単語」 |
| トークンテキスト | テキスト                 | 常時                 | 選択中トークンの表示テキスト                           |
| `分解する`       | ボタン (outline / small) | フレーズトークンのみ | フレーズを元の個別単語に分解する                       |

#### 分析フィールド

| フィールド         | 種別           | 条件                                        | 説明                                                                                                                                  |
| ------------------ | -------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 品詞               | セレクト       | 常時                                        | 上記15種の品詞から選択                                                                                                                |
| 変化形             | セレクト       | `partOfSpeech` が `verb` / `be-verb` のとき | 動詞の語形（原形・現在形・3単現形・過去形・現在進行形・過去進行形・現在完了形・過去完了形・未来形・不定詞・動名詞・過去分詞）から選択 |
| 数                 | セレクト       | `partOfSpeech === 'noun'` のとき            | 単数形 / 複数形から選択                                                                                                               |
| 変化形             | セレクト       | `partOfSpeech === 'to-infinitive'` のとき   | to不定詞の用法（名詞的用法 / 形容詞的用法 / 副詞的用法）から選択                                                                      |
| 単語としての意味   | テキストエリア | 通常トークン                                | 単語・フレーズの基本的な意味を入力                                                                                                    |
| 慣用句としての意味 | テキストエリア | フレーズトークン                            | 慣用句・イディオムとしての意味を入力                                                                                                  |

## ユーザー操作

| 操作                                                          | 結果                                                                                                  |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| トークンチップをクリック（通常モード）                        | 選択（アクティブ化）し分析パネルを表示。再クリックで選択解除                                          |
| トークンチップをクリック（隣接フレーズ作成モード）            | 選択状態をトグル                                                                                      |
| 分析フィールドを変更                                          | `isDirty` をtrueにし、`保存` ボタンを有効化                                                           |
| `隣接フレーズを作成` をクリック                               | 隣接フレーズ作成モードをONにする。アクティブトークンと選択状態をリセット                              |
| `選択中...` をクリック                                        | 隣接フレーズ作成モードをOFFにする                                                                     |
| 隣接フレーズ作成モードで隣接トークンを複数選択し `グループ化` | 選択トークンを1つのフレーズトークンに合成し、モードをOFF                                              |
| 分析パネルの `分解する` をクリック                            | フレーズトークンを元の個別単語に分解                                                                  |
| `パターンを作成` をクリック                                   | パターン作成モードをONにする。アクティブトークンと選択状態をリセット                                  |
| パターン作成モードでトークンを2つ以上選択し `パターンに登録`  | 選択トークン（英文中の順）を構成とするパターンを追加し、モードをOFF。追加したパターンのパネルを開く   |
| 連結線上のパターンラベルをクリック                            | パターンパネルを開く（開いているトークンの分析パネルは閉じる）。再クリックで閉じる                    |
| パターンパネルで意味を変更・`削除` をクリック                 | `isDirty` をtrueにし、`保存` ボタンを有効化                                                           |
| 意訳テキストエリアを変更                                      | `isDirty` をtrueにし、`保存` ボタンを有効化                                                           |
| タグを追加・削除                                              | `isDirty` をtrueにし、`保存` ボタンを有効化                                                           |
| `保存` をクリック                                             | `router.put('/sentences/{id}', toPayload({ tokens, patterns, naturalTranslation, tags }))` を呼び出す |
| `← 戻る` をクリック（変更なし）                               | `/` へ遷移                                                                                            |
| `← 戻る` をクリック（未保存の変更あり）                       | 確認ダイアログを表示し、承認で `/` へ遷移                                                             |

## 画面遷移

```
英文一覧ページ (/)
       ↑
       │ [← 戻る]
       │
英文詳細ページ (/sentences/:sentenceId)
```

保存後は `PUT /sentences/:id` が同じ `/sentences/:id` へ 303 リダイレクトするため、更新後のデータでページが再描画される（エディターは最新の保存内容で再マウントされる）。

## ページ状態

`Show` はサーバから props を受け取るだけで、データ取得用の state は持たない（`useEffect + fetch` は無し）:

| props            | 型                 | 説明                                                       |
| ---------------- | ------------------ | ---------------------------------------------------------- |
| `sentence`       | `Sentence \| null` | 表示中の英文データ。存在しない ID の場合は `null`          |
| `tagSuggestions` | `string[]`         | タグ入力のサジェスト候補（サーバの `fetchAllTags()` 由来） |

`SentenceEditor` が内部で保持するエディター状態:

| 状態変数             | 型                              | 説明                                                    |
| -------------------- | ------------------------------- | ------------------------------------------------------- |
| `tokens`             | `TokenWithAnalysis[]`           | 編集中のトークン一覧                                    |
| `patterns`           | `Pattern[]`                     | 編集中のパターン一覧                                    |
| `naturalTranslation` | `string`                        | 意訳テキスト                                            |
| `tags`               | `string[]`                      | 編集中のタグ一覧                                        |
| `activeId`           | `string \| null`                | 選択中トークンのID                                      |
| `activePatternId`    | `string \| null`                | パターンパネルで編集中のパターンのID                    |
| `selectMode`         | `'phrase' \| 'pattern' \| null` | 複数選択モード（隣接フレーズ作成 / パターン作成 / OFF） |
| `selected`           | `Set<string>`                   | 複数選択モードで選択中のトークンIDセット                |
| `isDirty`            | `boolean`                       | 未保存の変更があるかどうか                              |

## 特殊状態

| 状態                              | 表示                                                      |
| --------------------------------- | --------------------------------------------------------- |
| URLのIDに対応する英文が存在しない | `sentence` が `null` のため「英文が見つかりません」を表示 |

## サーバとのやり取り（Inertia）
