# 英文詳細ページ

## 概要

英文のトークン分解・品詞分析を行うページ。英文をトークン（単語・フレーズ）単位で操作し、各トークンへの品詞・語形・意味の入力と意訳の記入ができる。あわせて英文へのタグ（「過去文」「あいさつ文」など）の付与・編集もできる。

## ルート

| 項目                 | 値                                                                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| URL                  | `/sentences/:id`                                                                                                                             |
| サーバルート         | `GET /sentences/:id`（`app/server.tsx`）。対象 `sentence`（無ければ `null`）と `fetchAllTags()` を props で渡す。保存は `PUT /sentences/:id` |
| ページコンポーネント | `app/pages/Sentences/Show.tsx`（props を `PageProps<'Sentences/Show'>` で受領）                                                              |
| UIコンポーネント     | `src/components/SentenceEditor/SentenceEditor.tsx`, `src/components/TagInput/TagInput.tsx`                                                   |

**トークン未選択時（通常モード）:**

```
  トークンをクリックして分析情報を入力できます   ← 空ヒント
```

**フレーズ作成モード中:**

```
  フレーズ操作:  [選択中...]  [グループ化]   ← 隣接選択時にグループ化ボタンが出現
               隣接したトークンのみグループ化できます  ← 非隣接選択時に警告
               グループ化したいトークンを選択してください  ← 未選択時のヒント
```

## 要素仕様

### エディターヘッダー

| 要素         | 種別             | 説明                                                                            |
| ------------ | ---------------- | ------------------------------------------------------------------------------- |
| `← 戻る`     | ボタン (outline) | 英文一覧ページへ戻る。未保存の変更がある場合は確認ダイアログを表示              |
| 英文テキスト | テキスト (`p`)   | 英文の原文を表示（編集不可）                                                    |
| `保存`       | ボタン (primary) | 分析データを `router.put` でサーバに保存する。変更がない場合は無効 (`disabled`) |

### トークンツールバー

| 要素             | 種別                     | 説明                                                                                 |
| ---------------- | ------------------------ | ------------------------------------------------------------------------------------ |
| `フレーズを作成` | ボタン (outline / small) | フレーズ作成モードをONにする                                                         |
| `選択中...`      | ボタン (active / small)  | フレーズ作成モードON時に表示。クリックでモードをOFFにする                            |
| `グループ化`     | ボタン (primary / small) | 隣接する2つ以上のトークンを選択した場合に出現。クリックでフレーズトークンに合成する  |
| 警告テキスト     | テキスト                 | 非隣接トークンを選択した場合に「隣接したトークンのみグループ化できます」を表示       |
| ヒントテキスト   | テキスト                 | フレーズ作成モードON・未選択時に「グループ化したいトークンを選択してください」を表示 |

### トークンチップ

各トークンはボタン要素として表示される。

| 要素             | 条件                               | 説明                                     |
| ---------------- | ---------------------------------- | ---------------------------------------- |
| トークンテキスト | 常時                               | 単語またはフレーズの表示テキスト         |
| 品詞バッジ       | 通常モード・品詞設定済み           | 品詞名を色付きバッジで表示（後述）       |
| 語形バッジ       | 通常モード・動詞の語形設定済み     | 動詞変化形名をバッジで表示               |
| 数バッジ         | 通常モード・名詞の数設定済み       | 単数形/複数形をバッジで表示              |
| 用法バッジ       | 通常モード・to不定詞の用法設定済み | 名詞的/形容詞的/副詞的用法をバッジで表示 |
| 語義テキスト     | 通常モード・語義入力済み           | 単語の意味を最大2行で表示                |
| 慣用句テキスト   | 通常モード・慣用句の意味入力済み   | 「慣: {意味}」の形式で表示               |

**品詞バッジの色分け (`data-pos` 属性):**

| 品詞                                 | 表示名     |
| ------------------------------------ | ---------- |
| 名詞 (`noun`)                        | 名詞       |
| 代名詞 (`pronoun`)                   | 代名詞     |
| 疑問代名詞 (`interrogative-pronoun`) | 疑問代名詞 |
| 動詞 (`verb`)                        | 動詞       |
| be動詞 (`be-verb`)                   | be動詞     |
| 形容詞 (`adjective`)                 | 形容詞     |
| 副詞 (`adverb`)                      | 副詞       |
| 前置詞 (`preposition`)               | 前置詞     |
| 接続詞 (`conjunction`)               | 接続詞     |
| 定冠詞 (`definite-article`)          | 定冠詞     |
| 不定冠詞 (`indefinite-article`)      | 不定冠詞   |
| 感嘆詞 (`interjection`)              | 感嘆詞     |
| to不定詞 (`to-infinitive`)           | to不定詞   |
| その他 (`other`)                     | その他     |

**チップのスタイル状態:**

| 状態       | CSS クラス              | 条件                       |
| ---------- | ----------------------- | -------------------------- |
| 通常       | `.token-chip`           | デフォルト                 |
| フレーズ   | `.token-chip--phrase`   | `memberTexts.length > 1`   |
| アクティブ | `.token-chip--active`   | 通常モードで選択中         |
| 選択済み   | `.token-chip--selected` | フレーズ作成モードで選択中 |

### 意訳エリア

| 要素           | 種別             | 説明                                                                           |
| -------------- | ---------------- | ------------------------------------------------------------------------------ |
| 意訳           | ラベル (`label`) | テキストエリアのラベル                                                         |
| テキストエリア | `textarea`       | 文章全体の自然な日本語訳を入力する。行数は3行。変更時に `isDirty` をtrueにする |

### タグエリア（`TagInput`）

英文へ付与するタグの表示・編集を行う。

| 要素           | 種別                | 説明                                                                        |
| -------------- | ------------------- | --------------------------------------------------------------------------- |
| タグ           | ラベル              | タグエリアの見出し                                                          |
| タグチップ     | チップ + `×` ボタン | 付与済みのタグ。`×` クリックで削除                                          |
| 入力フィールド | `text` 入力         | タグ文字列を入力する。`datalist` で既存タグ（`fetchAllTags()`）をサジェスト |

タグ入力の挙動（`Enter`/`,` で追加、空欄で `Backspace` により末尾削除、`blur` で確定、`normalizeTags()` による正規化）は英文追加ページと共通。タグを変更すると `isDirty` がtrueになり、`保存` ボタンが有効化される。

### 分析パネル（トークン選択時のみ表示）

通常モードでトークンチップをクリックした場合に表示される。フレーズ作成モード中は非表示。

#### パネルヘッダー

| 要素             | 種別                     | 条件                 | 説明                                                   |
| ---------------- | ------------------------ | -------------------- | ------------------------------------------------------ |
| 種別ラベル       | テキスト                 | 常時                 | フレーズトークンは「フレーズ」、通常トークンは「単語」 |
| トークンテキスト | テキスト                 | 常時                 | 選択中トークンの表示テキスト                           |
| `分解する`       | ボタン (outline / small) | フレーズトークンのみ | フレーズを元の個別単語に分解する                       |

#### 分析フィールド

| フィールド         | 種別           | 条件                                      | 説明                                                                                                                                          |
| ------------------ | -------------- | ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 品詞               | セレクト       | 常時                                      | 上記14種の品詞から選択                                                                                                                        |
| 変化形             | セレクト       | `partOfSpeech === 'verb'` のとき          | 動詞の語形（原形・現在形・3単現形・過去形・現在進行形・過去進行形・現在完了形・過去完了形・未来形・不定詞・動名詞・過去分詞・助動詞）から選択 |
| 数                 | セレクト       | `partOfSpeech === 'noun'` のとき          | 単数形 / 複数形から選択                                                                                                                       |
| 変化形             | セレクト       | `partOfSpeech === 'to-infinitive'` のとき | to不定詞の用法（名詞的用法 / 形容詞的用法 / 副詞的用法）から選択                                                                              |
| 単語としての意味   | テキストエリア | 通常トークン                              | 単語・フレーズの基本的な意味を入力                                                                                                            |
| 慣用句としての意味 | テキストエリア | フレーズトークン                          | 慣用句・イディオムとしての意味を入力                                                                                                          |

## ユーザー操作

| 操作                                                      | 結果                                                                                        |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| トークンチップをクリック（通常モード）                    | 選択（アクティブ化）し分析パネルを表示。再クリックで選択解除                                |
| トークンチップをクリック（フレーズ作成モード）            | 選択状態をトグル                                                                            |
| 分析フィールドを変更                                      | `isDirty` をtrueにし、`保存` ボタンを有効化                                                 |
| `フレーズを作成` をクリック                               | フレーズ作成モードをONにする。アクティブトークンと選択状態をリセット                        |
| `選択中...` をクリック                                    | フレーズ作成モードをOFFにする                                                               |
| フレーズ作成モードで隣接トークンを複数選択し `グループ化` | 選択トークンを1つのフレーズトークンに合成し、モードをOFF                                    |
| 分析パネルの `分解する` をクリック                        | フレーズトークンを元の個別単語に分解                                                        |
| 意訳テキストエリアを変更                                  | `isDirty` をtrueにし、`保存` ボタンを有効化                                                 |
| タグを追加・削除                                          | `isDirty` をtrueにし、`保存` ボタンを有効化                                                 |
| `保存` をクリック                                         | `router.put('/sentences/{id}', toPayload({ tokens, naturalTranslation, tags }))` を呼び出す |
| `← 戻る` をクリック（変更なし）                           | `/` へ遷移                                                                                  |
| `← 戻る` をクリック（未保存の変更あり）                   | 確認ダイアログを表示し、承認で `/` へ遷移                                                   |

## 画面遷移

```
英文一覧ページ (/)
       ↑
       │ [← 戻る]
       │
英文詳細ページ (/sentences/:sentenceId)
```

保存後は `PUT /sentences/:id` が同じ `/sentences/:id` へ 303 リダイレクトするため、更新後のデータでページが再描画される（エディターは最新の保存内容で再マウントされる）。

## ページ状態

`Show` はサーバから props を受け取るだけで、データ取得用の state は持たない（`useEffect + fetch` は無し）:

| props            | 型                 | 説明                                                       |
| ---------------- | ------------------ | ---------------------------------------------------------- |
| `sentence`       | `Sentence \| null` | 表示中の英文データ。存在しない ID の場合は `null`          |
| `tagSuggestions` | `string[]`         | タグ入力のサジェスト候補（サーバの `fetchAllTags()` 由来） |

`SentenceEditor` が内部で保持するエディター状態:

| 状態変数             | 型                    | 説明                                         |
| -------------------- | --------------------- | -------------------------------------------- |
| `tokens`             | `TokenWithAnalysis[]` | 編集中のトークン一覧                         |
| `naturalTranslation` | `string`              | 意訳テキスト                                 |
| `tags`               | `string[]`            | 編集中のタグ一覧                             |
| `activeId`           | `string \| null`      | 選択中トークンのID                           |
| `isPhraseMode`       | `boolean`             | フレーズ作成モードのON/OFF                   |
| `selected`           | `Set<string>`         | フレーズ作成モードで選択中のトークンIDセット |
| `isDirty`            | `boolean`             | 未保存の変更があるかどうか                   |

## 特殊状態

| 状態                              | 表示                                                      |
| --------------------------------- | --------------------------------------------------------- |
| URLのIDに対応する英文が存在しない | `sentence` が `null` のため「英文が見つかりません」を表示 |

## サーバとのやり取り（Inertia）

| タイミング        | 方式                                              | 説明                                                                                                           |
| ----------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| ページ表示        | `GET /sentences/:id` → props                      | 対象 `sentence`（`fetchSentence`）と `fetchAllTags()` のタグ候補を props で受領（サーバ側で並行取得）          |
| `保存` クリック時 | `router.put('/sentences/{id}', toPayload({...}))` | サーバの `PUT /sentences/:id`（`updateSentence`）が JSON ファイルに保存し、同 URL へ 303 リダイレクト → 再描画 |
