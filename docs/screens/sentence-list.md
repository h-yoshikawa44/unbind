# 英文一覧ページ

## 概要

登録済みの英文を一覧表示するページ。各英文の編集・削除、および新規英文の追加を起点とする画面。
英文に付与されたタグを一覧に表示し、タグによる絞り込みに加え、キーワード（英文・和訳）による絞り込みも行える。
一覧は1ページあたり20件で表示し、（絞り込み後の）件数が20件を超える場合はページ送りで閲覧する。

## ルート

| 項目                 | 値                                                                                                                               |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| URL                  | `/`（タグ絞り込み時: `/?tags=過去文,あいさつ文`、キーワード絞り込み時: `/?q=hello world`、2ページ目以降: `/?page=2`）            |
| サーバルート         | `GET /`（`app/server.tsx`）。`fetchSentences()` の全件と `fetchAllTags()` を props として渡す                                    |
| ページコンポーネント | `app/pages/Sentences/Index.tsx`（props を `PageProps<'Sentences/Index'>` で受領）                                                |
| UIコンポーネント     | `src/components/SentenceList/SentenceList.tsx`, `src/components/TagInput/TagInput.tsx`（絞り込みバーは `SentenceList` 内に実装） |

絞り込み・ページングは当面クライアント側で行う（サーバは全件を渡す）。クエリパラメータの状態は `Index.tsx` がローカル state で保持し、`history.replaceState` で URL に同期する（サーバへは問い合わせない）。

### クエリパラメータ

| パラメータ | 型                 | 説明                                                                                                                                                                                                                                                                                             |
| ---------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `tags`     | カンマ区切り文字列 | 絞り込むタグ。例: `?tags=過去文,あいさつ文`。指定したタグを **すべて含む（AND）** 英文のみ表示する。未指定時は全件表示。`Index.tsx` の `readInitialSearch()` で正規化（前後空白の除去・空要素の除外・重複排除）する                                                                              |
| `q`        | 空白区切り文字列   | 絞り込むキーワード。例: `?q=hello world`。空白区切りで複数指定でき、指定したキーワードを **すべて含む（AND）** 英文のみ表示する。各英文の **英文テキストと和訳** を対象に大文字小文字を区別せず部分一致で判定する。未指定時は全件表示。`Index.tsx` の `readInitialSearch()` で前後空白を除去する |
| `page`     | 整数（1始まり）    | 表示するページ番号。例: `?page=2`。（絞り込み後の）英文を1ページ20件で分割した何ページ目かを表す。`readInitialSearch()` で 2 以上の整数のみ採用し、1ページ目は省略する。絞り込み条件を変更すると1ページ目に戻す。有効範囲を超える値は表示時に総ページ数へ丸める                                  |

`tags` と `q` は併用でき、両方指定時は「タグAND」かつ「キーワードAND」を満たす英文のみ表示する。ページングはこれらの絞り込みを適用した結果に対して行う。

## 要素仕様

### リストヘッダー

| 要素           | 種別             | 説明                     |
| -------------- | ---------------- | ------------------------ |
| 英文一覧       | 見出し (`h2`)    | ページタイトル           |
| `+ 英文を追加` | ボタン (primary) | 英文追加ページへ遷移する |

### 絞り込みバー（常に表示）

| 要素                   | 種別           | 説明                                                                                                                                                          |
| ---------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `キーワードで絞り込み` | ラベル         | キーワード入力欄の見出し                                                                                                                                      |
| キーワード入力欄       | 検索入力       | 常設。英文テキストと和訳を対象に部分一致（大文字小文字を区別しない）で絞り込む。空白区切りで複数キーワードを AND 指定可                                       |
| `タグで絞り込み`       | ラベル         | タグチップの見出し（付与済みタグが1つ以上ある場合のみ表示）                                                                                                   |
| タグチップ             | トグルボタン   | 登録済みの全英文で使われているタグを50音/アルファベット順に列挙。クリックで選択/解除を切り替え。選択中はハイライト表示。付与済みタグが1つ以上ある場合のみ表示 |
| `クリア`               | リンク風ボタン | キーワード行の右端に配置。絞り込み中（タグ選択中またはキーワード入力中）のみ表示。すべてのタグ選択とキーワードを解除して全件表示に戻す                        |

### 英文アイテム（一覧に英文が存在する場合）

| 要素         | 種別                    | 説明                                                        |
| ------------ | ----------------------- | ----------------------------------------------------------- |
| 英文テキスト | ボタン（行全体）        | クリックで英文詳細ページへ遷移する                          |
| タグ         | チップ（表示のみ）      | 英文に付与されたタグを列挙。タグがない場合は非表示          |
| メタ情報     | テキスト                | `{トークン数} トークン · {最終更新日 (ja-JP)}` の形式で表示 |
| `削除`       | ボタン (danger / small) | 確認ダイアログを表示し、承認で削除する                      |

英文アイテムは（絞り込み後の）一覧のうち、現在のページに対応する最大20件のみを表示する。

### ページングフッター（総ページ数が2以上のときのみ表示）

| 要素       | 種別     | 説明                                                                    |
| ---------- | -------- | ----------------------------------------------------------------------- |
| `← 前へ`   | ボタン   | 1つ前のページへ移動。1ページ目では非活性                                |
| ページ状態 | テキスト | `{現在ページ} / {総ページ数} ページ（全 {絞り込み後の件数} 件）` を表示 |
| `次へ →`   | ボタン   | 1つ後のページへ移動。最終ページでは非活性                               |

### 空状態

| ケース                          | 案内テキスト                                 | `最初の英文を追加する` ボタン |
| ------------------------------- | -------------------------------------------- | ----------------------------- |
| 英文が1件もない                 | 「まだ英文が登録されていません。」           | 表示する（primary）           |
| 絞り込み結果が0件（英文はある） | 「絞り込み条件に一致する英文はありません。」 | 表示しない                    |

`最初の英文を追加する` ボタンは英文追加ページへ遷移する（`+ 英文を追加` と同じ動作）。

## ユーザー操作

| 操作                               | 結果                                                                                                                                                               |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `+ 英文を追加` をクリック          | `/sentences/new` へ遷移                                                                                                                                            |
| 英文アイテム本体をクリック         | `/sentences/{id}` へ遷移                                                                                                                                           |
| 未選択のタグチップをクリック       | そのタグを絞り込み条件に追加し、URLの `tags` を更新（例: `/?tags=過去文`）                                                                                         |
| 選択中のタグチップをクリック       | そのタグを絞り込み条件から除外し、URLの `tags` を更新（全解除時は `tags` を除去）                                                                                  |
| キーワード入力欄に文字を入力       | 入力内容で即時に絞り込み、URLの `q` を更新（履歴を汚さないよう `history.replaceState` で更新。空にした場合は `q` を除去）。あわせて `page` を除去し1ページ目に戻す |
| `クリア` をクリック                | すべてのタグ選択とキーワードを解除し、URL を `/` に戻す                                                                                                            |
| `← 前へ` / `次へ →` をクリック     | 前後のページへ移動し、URLの `page` を更新（1ページ目は `page` を除去）                                                                                             |
| `削除` をクリック                  | 確認ダイアログを表示                                                                                                                                               |
| 削除確認ダイアログで「OK」         | `router.delete('/sentences/{id}')` を呼ぶ。サーバは `DELETE /sentences/:id` で削除し `/` へ 303 リダイレクト → 一覧が再取得される                                  |
| 削除確認ダイアログで「キャンセル」 | 何もしない                                                                                                                                                         |

タグチップの操作でも `page` を除去して1ページ目に戻す。

絞り込み・ページング（タグ・キーワード・ページ番号）の状態はURLのクエリパラメータで保持するため、リロード・URL共有に対応する（キーワードは初期表示時に URL の `q` から復元する）。

**削除確認ダイアログのメッセージ例:**

```
"The quick brown fox..." を削除しますか？
```

（英文テキストが40文字を超える場合は末尾を `...` で省略する）

## 画面遷移

```
英文追加ページ (/sentences/new)  ←──┐
                                    │  [+ 英文を追加]
英文一覧ページ (/)  ────────────────┤
                                    │  [英文アイテムをクリック]
英文詳細ページ (/sentences/{id})  ←─┘
```

## ページ状態

| 状態変数               | 型           | 説明                                                                                                                            |
| ---------------------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `sentences`            | `Sentence[]` | 全英文。サーバの `GET /`（`fetchSentences()`）から props で受領（`PageProps<'Sentences/Index'>`）                               |
| `allTags`              | `string[]`   | 絞り込みバー用のタグ候補。サーバの `fetchAllTags()` から props で受領                                                           |
| `selectedTags`         | `string[]`   | 絞り込み中のタグ。URL の `tags` から初期化し、ローカル state で保持（変更時に `history.replaceState` で同期）                   |
| `keyword`              | `string`     | キーワード入力欄の値。入力の追従性のためローカル `useState` で保持し、初期値は URL の `q` から復元する                          |
| `keywords`             | `string[]`   | `keyword` を空白で分割した検索語の配列（AND 判定に使用）                                                                        |
| `filteredSentences`    | `Sentence[]` | `selectedTags` をすべて含み（AND）、かつ `keywords` をすべて英文・和訳に含む（AND）英文のみに絞った表示用リスト。未指定時は全件 |
| `totalPages`           | `number`     | `filteredSentences` の件数を1ページ20件（`PAGE_SIZE`）で割った総ページ数（最小1）                                               |
| `page` / `currentPage` | `number`     | `page` はローカル state（初期値は URL の `page` 由来）。`currentPage` はそれを `[1, totalPages]` に丸めた表示中ページ           |
| `pagedSentences`       | `Sentence[]` | `filteredSentences` から `currentPage` に対応する最大20件を切り出した、実際に描画するリスト                                     |

`PAGE_SIZE`（= 20）は `Index.tsx` の定数。`allTags` はサーバ側で算出済みのため、以前あった `sentences` からの再算出は行わない。

## サーバとのやり取り（Inertia）

| タイミング | 方式                               | 説明                                                                                 |
| ---------- | ---------------------------------- | ------------------------------------------------------------------------------------ |
| ページ表示 | `GET /` → props                    | `fetchSentences()` の全英文と `fetchAllTags()` のタグ候補を props で受領             |
| 削除確認後 | `router.delete('/sentences/{id}')` | サーバの `DELETE /sentences/:id`（`deleteSentence`）で削除し `/` へ 303 リダイレクト |
